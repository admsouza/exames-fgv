# Pontos fracos

Este arquivo deve refletir o diagnóstico atual, não uma lista permanente. Atualize-o com base nos dados de `desempenho/questoes.jsonl`.

## Prioridade alta

_Assuntos com baixo desempenho, alta incidência ou erros recorrentes._

## Prioridade média

_Assuntos com desempenho intermediário ou domínio instável._

## Prioridade baixa

_Assuntos com bom desempenho e baixa necessidade de revisão._

## Observações

- Acertos com confiança baixa também devem ser tratados como sinal de fragilidade.
- Um assunto só deve sair da prioridade alta após melhora consistente em novas questões.
